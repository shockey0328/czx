# 用户行为看板 · 工具包清单与使用说明

> 完整代码位于 `用户行为看板（周度）/`。参赛附件侧重可带走清单与用法。

## 1. 产品入口

| 入口 | 说明 |
| --- | --- |
| https://d1.fuxue.work/ | 统一门户 → 周度 → 用户行为 |
| https://d1.fuxue.work/user-behavior.html | 公网说明/跳转页 |
| `intranet-user-behavior.json` | 配置内网完整服务地址 |
| `dashboard-db.html` | 看板主页面（需后端） |

## 2. 服务与 API

| 文件/目录 | 作用 |
| --- | --- |
| `server-with-db.js` | 主服务入口（本地/内网） |
| `database.js` / `db-manager.js` | 本地 JSON 索引与查询 |
| `api/analyze.js` | AI 分析接口 |
| `api/getData.js` / `api/cloudData.js` / `api/stats.js` | 取数与统计 |
| `lib/warehouseData.js` / `lib/mcpHttpClient.js` | 数仓 MCP 取数 |
| `scripts/export-from-warehouse.js` | 按日从数仓导出 JSON |

## 3. 数据与存储模式

- 按日分片：`data/YYYY-MM-DD.json`  
- 双重索引：用户索引 + 日期索引  
- 线上推荐：导出 → 云存储/Release → Serverless 读取  
- 内网可选：`DATA_SOURCE=warehouse` 按用户实时查询（勿在公网 Serverless 上对全量实时 MCP）

## 4. AI 能力

- 模型：DeepSeek（环境变量 `DEEPSEEK_API_KEY`）  
- 常规性分析：轨迹 / 习惯 / 卡点 / 建议  
- 针对性分析：问题定位 → 原因 → 证据 → 建议  
- 只基于真实日志，不编造未出现的操作

## 6. 最小复制套件

1. 按用户 ID + 日期查询的服务与页面  
2. 常规/针对性两套 AI Prompt  
3. 数仓导出脚本 + 更新 SOP  
4. 《使用说明》业务分享文档  
5. 门户跳转配置（intranet-user-behavior.json）

## 7. 质量底线

- 禁止编造用户行为或补全未发生的点击  
- 查无数据时明确提示，不用假轨迹顶替  
- 密钥与 MCP Key 不入库  
- 单次分析建议日期范围 ≤ 7 天
