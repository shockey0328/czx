# 用户行为看板 · 作品演示脚本

> 用途：答辩讲解、录屏旁白、PPT 提纲。建议总时长 6～10 分钟。  
> 门户入口：https://d1.fuxue.work/ （周度 → 用户行为）  
> 范围：仅用户行为看板；核心数据等汇总看板不在本申报演示重点内。

## 一句话开场（20 秒）

这不是看整体 UV、留存的大盘，而是一台「用户个案放大镜」：已知用户 ID 后，还原他在橙子学 / 学伴里做了什么，并用 AI 生成产品、运营可读的行为解读报告。

## 演示步骤

### 1. 定位差异（40 秒）

- 汇总看板回答：这周整体怎么样？  
- 本看板回答：这个用户为什么流失 / 卡在哪一步？  
- 强调：必须先有数字用户 ID；一次建议查 ≤ 7 天

### 2. 打开入口（30 秒）

1. 打开 https://d1.fuxue.work/  
2. 选择周度 → 看板类型选「用户行为」  
3. 说明：完整取数与 AI 分析依赖后端服务；若跳转内网地址，需公司网络或 VPN  
4. 进入看板后指认：日期、用户 ID、分析模式、小橙子对话框

### 3. 常规性分析（2～3 分钟）

1. 选可用日期范围内的起止日期（建议 ≤ 7 天）  
2. 填入一个真实用户 ID（演示前准备好，勿编造日志）  
3. 选择「常规性分析」  
4. 提问示例：`分析用户的完整使用路径`  
5. 讲解四段报告：轨迹 → 习惯 → 卡点（重点）→ 建议  
6. 指出报告底部「基于 N 条记录」，强调只依据真实埋点

### 4. 针对性分析（2 分钟）

1. 切换「针对性分析」  
2. 提问示例：`为什么用户在搜索后就流失了？` 或 `用户在哪个环节卡住了？`  
3. 说明输出更贴近问题：定位 → 原因 → 证据 → 建议

### 5. 分角色价值（60 秒）

- 产品：反馈复盘、改版验证、转化个案卡点  
- 运营：高价值/沉默用户、流失召回停点  
- 教研：找卷、预览、练习、学伴相关路径（不替代内容质量评估）

### 6. 工程与数据链路收尾（60 秒）

- 数据：数仓按日导出 JSON / 本地索引，或内网 MCP 按用户取数  
- AI：DeepSeek，密钥走环境变量  
- 可复用：使用说明、更新 SOP、导出脚本、Skill/规范

## 结束语（15 秒）

把「翻几十万行埋点」变成「选日期、填 ID、问一句」，让个案复盘可规模化、可复制。

## PPT 页建议（6 页）

1. 封面：橙子学用户行为看板  
2. 场景：个案 vs 大盘  
3. 方案：取数 + 索引/数仓 + AI 双模式  
4. 演示截图  
5. 效果与边界  
6. 复用：SOP / 工具包 / 使用说明
