# 用户行为看板 · 参赛申报材料使用说明

本套材料**仅申报用户行为看板**，与「核心数据看板」申报相互独立。

## 1. 结构化申报文档（必传）

| 项 | 说明 |
| --- | --- |
| 上传文件 | `结构化申报文档.md` |
| 大小限制 | ≤ 2MB |
| 标题要求 | `# 参赛思路` `# 问题说明` `# 方案说明` `# 效果说明` `# 复用说明` |
| 编码 | **UTF-8 无 BOM**（请直接上传，勿用记事本另存为再转编码） |

## 2. 成果附件（建议传）

| 限制 | 值 |
| --- | --- |
| 文件数 | ≤ 10 |
| 单文件 | ≤ 25MB |
| 总大小 | ≤ 35MB |

推荐上传 `成果附件包\` 内文件，或只传总包 zip。

演示相关地址：

- 门户入口：https://d1.fuxue.work/ （周度 → 用户行为）
- 直达说明页：https://d1.fuxue.work/user-behavior.html  
- 完整分析能力依赖内网/VPN 上的行为服务（见申报文档与 SOP）

## 3. 一键打包

```powershell
powershell -ExecutionPolicy Bypass -File "参赛申报材料-用户行为看板\打包成果附件.ps1"
```
