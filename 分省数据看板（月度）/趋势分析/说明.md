# 趋势分析数据说明

本文件夹存放各月 Excel（25年1月～26年2月），每表为全国各省份核心指标。

## 生成看板用数据（34 省）

在 **「分省数据看板（月度）」** 目录下执行：

```bash
python 趋势分析/build_trend_data.py
```

会读取本目录下所有 `XX年X月.xlsx`，生成 `趋势分析/trend-data.js`。  
看板会优先加载该文件，展示全国 34 个省份的趋势与排名。

## Excel 表结构要求

- 第一行为表头，需包含以下含义的列（列名可含下列关键字）：
  - **省份/地区**：省份名称
  - **活跃用户 / 月活**
  - **订单营收 / 营收**
  - **使用率**
  - **ARPU**
- 从第二行起每行一个省份。

若列名不一致，可修改 `build_trend_data.py` 中的 `PROVINCE_KEYS`、`ACTIVE_KEYS` 等常量。
