# 用户增长数据看板（周度）

面向「橙子学」的 **用户增长** 单页看板：数据按 **自然周** 汇总与筛选，核心指标支持 **环比**（相对上一周），渠道模块展示 **全部渠道来源**（按当期规模排序）。

**入口文件**：[`user-growth-dashboard.html`](./user-growth-dashboard.html)（浏览器直接打开或通过本地 HTTP 访问）。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **核心指标** | 新增用户、活跃用户、新用户占比、累计用户；环比为相对所选周的上一周；占比类环比用 **百分点（pp）** 展示。 |
| **趋势分析** | 三张 ECharts 图（活跃 / 新用户 / 新用户占比），按 **日** 聚合；「本周 / 近4周 / 近12周」以 **当前所选周** 为截止。 |
| **渠道分析** | 活跃渠道、新用户渠道饼图 + 表格；环比为渠道 UV 的相对变化；展示 **全部渠道**（不再合并为 Top5+其他）。 |
| **数据分析助手** | 基于当周数据自动生成摘要 + 演示对话（前端 Mock，非真实大模型 API）。 |
| **周筛选** | 页眉「选择周」下拉框：主序列来自 CSV 中 **当前统计年**（脚本内 `CURRENT_YEAR`，默认 `2026`）的周数据。 |

**涨跌配色**：涨 **红**、跌 **绿**（A 股习惯）。

---

## 数据文件（与 HTML 同目录）

| 文件 | 用途 |
|------|------|
| `周度用户核心数据.csv` | 周度核心：第 n 周、起止日期、活跃/新增/占比/累计等。 |
| `每天的活跃用户及新老用户.csv` | 日度趋势：`dt`、`active_uv`、`new_uv`、新用户占比等。 |
| `每周活跃用户的渠道来源.csv` | 渠道：`week_start` / `week_end` / `channel_name` / `uv`。 |
| `每周新用户的渠道来源.csv` | 渠道：`week_start` / `week_end` / `channel_name` / `new_user_uv` 或 `uv`。 |

**可选**：`每周活跃用户的渠道来源_fixed.csv` — 若默认文件名 fetch 失败，脚本会 **自动尝试** 该备选路径。

**渠道周对齐**：渠道表中的 `week_start` / `week_end` 与核心周区间存在固定 **4 天偏移**（`CHANNEL_SHIFT_DAYS`），在脚本中与核心周对齐后再匹配。

**日期格式**：支持 `2026-01-05` 与 `2026/1/5` 等，内部会规范化后对齐。

## 本地打开方式

1. **推荐**：在项目目录启动静态服务后访问 `user-growth-dashboard.html`，以便 `fetch` 能读取同目录 CSV（例如 `npx serve .`、VS Code Live Server 等）。
2. **直接双击 / `file://` 打开**：浏览器往往 **无法** 对本地文件执行 `fetch`，此时依赖 **`embedded-csv-b64.js`** 内嵌的 Base64 副本作为兜底。

---

## 生成内嵌数据 `embedded-csv-b64.js`

在 **本目录** 执行（需已安装 Node.js）：

```bash
npm install
node build-embedded-b64.js
```

- 会读取上述 4 个 CSV，生成/覆盖 **`embedded-csv-b64.js`**。
- 若 CSV 为 Excel 导出的 **GBK/GB18030**，脚本会通过 **`iconv-lite`** 转 UTF-8 再写入 Base64；并可将 CSV **回写为 UTF-8（无 BOM）**，便于 HTTP 下 fetch。

更新任一 CSV 后，若使用 `file://` 或需内嵌与文件完全一致，请 **重新运行** 该脚本。

## 维护提示

- 调整 **统计年份**：在 `user-growth-dashboard.html` 中修改常量 **`CURRENT_YEAR`**，并与 CSV 中「周开始日期」年份一致。
- 渠道数据量大时，饼图容器已使用 **最小高度 + 视口比例**，表格区域可横向滚动。
- 对话区为 **演示交互**，问题与回复规则在脚本内 `mockQA` / `getMockReply` 中维护。
